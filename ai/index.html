AI Engineering — Skills, Agents & Workflows

claude-dev-workflow

Author & maintainer · Open source

Aug 2026 — Present

Ticket-driven development for Claude Code against YouTrack or GitHub Issues, installed per project with no global state.

  • 15 skills cover the ticket lifecycle end to end: file, plan, split, build test-first, review and land
  • The build skill orchestrates builder subagents in the background, one per work unit in its own git worktree, landed a wave at a time
  • The review skill runs three adversarial reviewer subagents, each given a different payload: one never sees the ticket, one hunts the input that breaks the code, one audits code against intent
  • Hooks check that every commit references a ticket, keep architecture decision records immutable and open each session with a standup
  • Shipped on npm and Homebrew: 39 releases and 6,152 npm downloads in the 30 days to 11 Sept 2026, with CI, coverage reporting and a documentation site

claude-dev-workflow

Auteur & mainteneur · Open source

Août 2026 — Présent

Développement piloté par tickets pour Claude Code, sur YouTrack ou GitHub Issues, installé par projet sans aucun état global.

  • 15 skills couvrent tout le cycle de vie d'un ticket : création, plan, découpage, développement piloté par les tests, revue et livraison
  • Le skill de build orchestre des sous-agents développeurs en arrière-plan, un par unité de travail dans son propre worktree git, livrés vague par vague
  • Le skill de revue lance trois sous-agents relecteurs adversariaux, chacun avec un contexte différent : l'un ne voit jamais le ticket, l'un cherche l'entrée qui casse le code, l'un confronte le code à l'intention
  • Des hooks vérifient que chaque commit référence un ticket, rendent les décisions d'architecture (ADR) immuables et ouvrent chaque session par un point quotidien
  • Distribué sur npm et Homebrew : 39 versions et 6 152 téléchargements npm sur les 30 jours au 11 sept. 2026, avec CI, mesure de couverture et site de documentation
